# Readonly

A tiny static status page that answers whether today is read-only Friday based on the visitor's local date.

## Published Page

```text
https://numerate64.github.io/readonly/
```

## Files

- `index.html` - page markup and browser logic.
- `styles.css` - responsive card styling.
- `favicon.svg` - site icon.

## Notes

The result depends on the visitor's local clock and timezone. No backend is involved.
